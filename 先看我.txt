M-01 Companion　Mac 版安裝說明
================================

【需要準備】
1. Mac（M1／M2／M3／M4 晶片建議 16GB 記憶體以上）
2. Ollama（選用，想用本地 AI 才需要）：到 https://ollama.com/download 下載 Mac 版，打開安裝檔，把 Ollama 拖進「應用程式」，再打開一次。
   右上角選單列出現小羊駝圖示，就代表它在執行。

【安裝步驟】
1. 解壓縮這個 zip。
2. 打開「終端機」（按 Command + 空白鍵，輸入「終端機」，按 Enter）。
3. 在終端機輸入 bash，後面加一個空格（先不要按 Enter）。
4. 把「安裝 M-01 Companion.command」拖進終端機視窗，按 Enter。
5. 安裝程式會問你要哪個聊天模型：輸入 1 = 標準版 qwen3.5:9b（約 6.6GB，適合 16GB 以上的電腦），輸入 2 = 輕量版 qwen3.5:4b（約 3.3GB，適合 8GB 的電腦，但比較容易答錯）。安裝程式會看你的記憶體，直接按 Enter 就是建議的那個，輸入 3 = 不要本地 AI（只用 Gemini 或 Claude，最省空間）。等它下載完。
6. 第一次打開 App 會帶你確認記憶資料夾的位置，並教你用 Google 雲端硬碟備份。
6. 裝好會自動打開 App。之後從「應用程式」或 Launchpad 點「M-01 Companion」就能用。

【記憶存在哪裡】
「文件/Companion」資料夾：
・對話/日期.md　每天的對話紀錄
・記憶重點.md　她記下的重點，可以自己打開修改
・檔案/　你上傳過的檔案全文
・備份/　按「下載全部記憶備份」時存在這裡
・_資料（請勿修改）　App 自己用的，不要動
想在手機或別台電腦看：用「Google 雲端硬碟電腦版」把這個資料夾加入同步。

【常見問題】
Q：點兩下 .command 出現「無法驗證開發者」
A：一定要照步驟 2～4，用終端機執行，就不會被擋。

Q：App 上方顯示「連不到本地 AI」或「AI 未連線」
A：1. 確認選單列有 Ollama 小羊駝圖示；沒有就到「應用程式」打開 Ollama。
   2. 按 Command + Q 關掉 App，再重新打開。
   3. 還是不行：打開終端機，貼上 launchctl setenv OLLAMA_ORIGINS "*" 按 Enter，
      然後從選單列小羊駝選 Quit Ollama，再打開 Ollama 和 App。

Q：顯示「還沒下載模型」
A：最簡單：到 App 的「設定 → AI」，AI 來源選本地 AI，按「下載標準版」或「下載輕量版」，會顯示下載進度。
   或者：打開終端機，執行 ollama pull qwen3.5:9b（或輕量版 ollama pull qwen3.5:4b），跑完再重開 App。

Q：Dock 上的圖示不是 M-01
A：登出再登入一次 Mac，圖示快取就會更新。

Q：麥克風按了沒反應
A：新版按麥克風會直接叫出 Mac 的聽寫（實驗功能），出現麥克風小圖示就可以說話。
   第一次要到「系統設定 → 鍵盤 → 聽寫」打開；系統若問「要允許控制」請按允許。
   如果沒出現：點輸入框，按兩下 Fn（🌐）鍵也一樣。

Q：音量在哪裡調
A：右上角喇叭鍵點一下，會出現直立滑桿，往上拉變大聲，下面有「靜音」。

Q：她看不懂我傳的圖片
A：在終端機執行 ollama pull gemma3:4b，再到 App 的「設定 → LOCAL AI → 看圖模型」填 gemma3:4b。

Q：回答很慢
A：16GB 的 Mac 跑 7B 模型每秒約十幾到二十幾個字，屬正常。關掉其他吃記憶體的程式會快一點。
   她去查記憶或上網查證時，也會多等幾秒。

Q：想移除 App
A：把「應用程式」裡的 M-01 Companion 丟到垃圾桶即可。記憶資料夾「文件/Companion」不會被刪除。

Q：下載太大了
A：Ollama 本身加上模型，標準版總共約 7GB 以上。安裝時選 2（輕量版 qwen3.5:4b，約 3.3GB）可以省一半左右，但回答品質會差一些。App 會自動使用你裝好的模型。

Q：她講話很笨、跟網頁版差很多
A：網頁版用的是 Claude（很大的雲端模型），電腦版預設用的是在你電腦上跑的小模型，所以差很多是正常的。
   想要聰明一點：到 App 的「設定 → AI → AI 來源」選 Claude，貼上 Anthropic 的 API 金鑰（console.anthropic.com，按用量付費，跟 claude.ai 訂閱分開）。

Q：怎麼解除安裝
A：App 的「設定」最下面有「解除安裝 App」，可以選要不要一併刪除記憶資料（會移到垃圾桶／資源回收筒）和聊天模型。

Q：想要聰明一點但不想花錢
A：App 的「設定 → AI → AI 來源」選 Gemini，到 aistudio.google.com/apikey 用 Google 帳號免費建立金鑰，貼上就會自動儲存並測試。
   免費額度每分鐘、每天有次數上限；免費方案的對話內容 Google 可能會拿去改進產品。

Q：想讓她用聲音唸出回覆（Fish Audio）
A：到 fish.audio 註冊，進「API Keys」建立金鑰，貼到 App 的「設定 → VOICE」。
   語音模型選「S2.1 Pro Free」就是免費的（有合理使用限制）；想換聲音就貼上 fish.audio 聲音頁面的網址。
   口音跟著聲音走：「中文聲音」「英文聲音」可以各貼一個，「口音」選自動時中文回覆用中文聲音、英文回覆用英文聲音。
   打開「回覆完自動唸出來」，或按每則回覆下面的「朗讀」。請只用你自己做的或有授權的聲音。

Q：不想要本地 AI，或想省空間
A：安裝時選 3 就不會下載本地 AI，也不用裝 Ollama；打開 App 後貼上免費的 Gemini 金鑰就能用。
   已經裝了的話，到 App 的「設定 → AI」，可以看到每個本地模型佔多少空間，按「刪除」就能省下 2～5GB；之後想要再按「下載」。

Q：想在別台電腦、手機接著聊（Google 登入）
A：第一次打開 App 會問要不要用 Google 登入；之後也可以到「設定 → ACCOUNT」按「用 Google 登入」。
   會打開瀏覽器的 Google 登入頁，登入完自動回到 App。對話、記憶、角色圖和 AI 金鑰會存到你自己 Google 雲端硬碟裡的隱藏資料夾（只有 M-01 讀得到）。
   別台電腦裝好 App、或手機打開網頁版 https://elvis071114-coder.github.io/m01/ ，用同一個 Google 帳號登入，就會自動帶過來。
   不登入也可以，資料一樣存在這台電腦裡。

Q：哪個本地 AI 適合我的電腦？
A：App 的「設定 → AI 模型」會看你的記憶體，標出「建議你的電腦用這個」：
   8GB → 輕量版 qwen3.5:4b；16GB（或有 12GB 顯示卡）→ 標準版 qwen3.5:9b；32GB 以上的 Mac 或 20GB 以上的顯示卡 → 強力版 qwen3.5:27b。
   這些新模型自己看得懂圖片，也會先思考再回答。下載失敗的話，先到 https://ollama.com/download 更新 Ollama。

Q：角色旁邊的音樂（Spotify）沒有顯示
A：打開 Mac 上的 Spotify App 播一首歌，幾秒內就會出現。第一次 Mac 會問「M-01 Companion 想要控制 Spotify」，按「好」。
   不小心按了「不允許」：到「系統設定 → 隱私權與安全性 → 自動化」，把 M-01 Companion 底下的 Spotify 打開。
   免費帳號也能用，不用另外登入。網頁版看不到電腦上的 Spotify，只有 App 版有。
   從舊版更新上來的話，要重新跑一次安裝程式，音樂功能才會出現。

Q：天氣地點不對
A：天氣會依網路位置自動判斷（大約到城市）。到「設定 → 小工具」的「天氣地點」直接打城市名稱（例如：桃園、台中），或打開「使用精確位置」。
